# 📝 To-Do List App

A simple, lightweight To-Do List web application built using **HTML**, **CSS**, and **JavaScript**. Users can add, complete, delete tasks, and all tasks are saved in the browser using `localStorage`.

---

## 🚀 Features

- ✅ Add new tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 💾 Save tasks in browser (persistent across sessions)
